    Abstract

    This project uses a convolutional neural network based transfer learning pipeline to classify potato leaf images into disease categories. The system processes the uploaded image, performs preprocessing, runs inference through the trained TensorFlow model, and returns the predicted class with confidence and treatment suggestions.

    Methodology

    1. Upload

    The user selects a single leaf image in the browser. The file is previewed locally before being sent to the backend.

    2. Prediction

    Flask receives the image, preprocesses it to 224×224, and feeds it into the saved Keras model.

    3. Output

    The backend returns the predicted disease class, confidence score, class probabilities, and care advice.

    Project Notes

    Make sure the model file is placed beside server.py as potato_model.keras. The prediction labels should match the training label order: Early, Healty, Late.
